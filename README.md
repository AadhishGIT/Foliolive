# Foliolive: Real-Time Portfolio & Risk Analytics Platform

[![CI Pipeline](https://github.com/foliolive/foliolive/actions/workflows/ci.yml/badge.svg)](https://github.com/foliolive/foliolive/actions/workflows/ci.yml)
[![Node.js Version](https://img.shields.io/badge/Node.js-20+-brightgreen.svg)](https://nodejs.org/)
[![Java Version](https://img.shields.io/badge/Java-21+-orange.svg)](https://openjdk.org/)
[![TypeScript](https://img.shields.io/badge/TypeScript-Strict_Mode-blue.svg)](https://www.typescriptlang.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

An institutional-grade portfolio management and real-time risk analytics platform. Designed to demonstrate senior/lead frontend and full-stack engineering at scale: **Micro-Frontends (Module Federation over Vite)**, a shared **Radix/Tailwind design system**, **real-time streaming WebSocket telemetry**, **D3.js risk modeling**, **TanStack Virtual grid scaling**, **Java 21 Spring Boot 3 core**, **Prometheus/Grafana observability**, and **OWASP Top 10 security compliance**.

All market data is generated by an in-memory, deterministic **Geometric Brownian Motion (GBM)** simulator (zero paid APIs required; reproducible with fixed seed).

## Quick Start Guide

### Prerequisites

- Node.js >= 20.x
- pnpm >= 9.x / 12.x
- Docker & Docker Compose
- JDK 21+ (for local Java builds)

### 1. Local Monorepo Development (pnpm)

```bash
# Clone the repository
git clone https://github.com/foliolive/foliolive.git
cd foliolive

# Copy environment template
cp .env.example .env

# Install dependencies across all workspaces
pnpm install

# Run typecheck and linting
pnpm typecheck
pnpm lint

# Start all frontend apps and BFF concurrently
pnpm dev
```

The services will be available at:

- **Shell Host**: [http://localhost:3000](http://localhost:3000)
- **Portfolio MFE**: [http://localhost:3001](http://localhost:3001)
- **Risk MFE**: [http://localhost:3002](http://localhost:3002)
- **Alerts MFE**: [http://localhost:3003](http://localhost:3003)
- **BFF Gateway (HTTP & WS)**: [http://localhost:4000](http://localhost:4000)

### 2. Full Containerized Stack (Docker Compose)

```bash
# Build and start all services (Postgres, Core API, BFF, MFEs, Prometheus, Grafana)
docker compose up --build -d

# Check service health
docker compose ps
```

Additional container endpoints:

- **Core API**: [http://localhost:8080/actuator/health](http://localhost:8080/actuator/health)
- **Prometheus**: [http://localhost:9090](http://localhost:9090)
- **Grafana**: [http://localhost:3100](http://localhost:3100) (admin / admin)
