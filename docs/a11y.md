## 2. Core Accessibility Pillars

### 2.1 Contrast Ratios (WCAG 1.4.3 & 1.4.11)

- **Normal Text:** All body copy, table text, card metrics, and metadata utilize text color tokens (`#ffffff`, `#f1f5f9`, `#cbd5e1`, and `#94a3b8`) against dark backgrounds (`#020817` and `#0f172a`), achieving contrast ratios between **7.3:1 and 18.5:1** (exceeding the 4.5:1 WCAG AA minimum).
- **Large Text / Headings:** Institutional headings achieve contrast ratios exceeding **12:1** (exceeding the 3.0:1 threshold).
- **UI Components & Graphical Objects:** Interactive form controls, focus rings (`ring-2 ring-blue-500`), borders, and active tabs meet or exceed the 3.0:1 contrast ratio required for non-text contrast.

### 2.2 Non-Color Visual Differentiation (WCAG 1.4.1)

Institutional financial applications often rely solely on red/green for profit and loss or breach indicators, which fails users with deuteranopia or protanopia. Foliolive strictly forbids color as the sole conveyor of information:

- **`DeltaValue`:** Always combines color (`emerald-400` / `rose-400`) with explicit direction arrows (`ArrowUp` / `ArrowDown`) and mathematical signs (`+` / `-`).
- **D3 Donut Charts:** Slices use unique SVG pattern textures (diagonal stripes, polka dots, crosshatches, horizontal bars) in addition to distinctive color hues.
- **Risk Gauges:** Utilize numerical percentages, gauge needle markers, policy limit dashed thresholds, and status text pills (`Within Limit`, `Tail Safe`, `Limit Breached`).
- **Correlation Heatmap:** In addition to the continuous color scale, every cell renders explicit numerical correlation coefficients (`0.00` to `1.00`), readable in both high contrast and screen reader modes.

### 2.3 Pure D3 Accessible Chart Alternatives (WCAG 1.1.1 & 1.3.1)

All custom D3 SVG visualizations (`SectorAllocationChart`, `PnLTimeSeriesChart`, `ExposureBarChart`, `ConcentrationChart`, `CorrelationHeatmap`, `VaRHistoryChart`) feature dual representation:

1. **Interactive SVG Canvas:** Configured with `role="img"`, descriptive `aria-label`, and keyboard focusable SVG elements.
2. **Hidden Screen-Reader Data Table:** A semantic, visually hidden HTML table (`<table className="sr-only">`) with captions, column headers (`<th>`), and tabular rows (`<td>`) mirroring the exact underlying data structure for screen readers (NVDA, VoiceOver, JAWS).

### 2.4 Keyboard Navigation & ARIA Patterns (WCAG 2.1.1 & 2.1.2)

- **Skip Links:** Top of page includes a `<SkipLink targetId="main-content">` allowing keyboard users to bypass header navigation and jump directly to active analytics.
- **ARIA Grid Pattern (`VirtualizedGrid`):** The 500+ and 10,000-row holdings grid implements the full WAI-ARIA Grid design pattern:
  - `role="grid"` with `aria-rowcount` and `aria-colcount` reflecting virtualized dataset boundaries.
  - Arrow key navigation (`ArrowDown`, `ArrowUp`, `Home`, `End`, `PageUp`, `PageDown`) updates focused row selection and auto-scrolls the TanStack virtualizer.
  - Spacebar / Enter on sortable column headers activates asc/desc sort toggles.
- **Accessible Modal Dialogs:** Built with Radix UI primitives (`@radix-ui/react-dialog`) providing automatic focus trapping, accessible `aria-labelledby` and `aria-describedby` associations, and dismissal via the `Escape` key.

### 2.5 Real-Time Live Region Throttling (WCAG 4.1.3)

- Real-time updates emitted by the WebSocket feed and market simulator do not flood screen readers.
- Alerts use an `aria-live="polite"` region with debounced message queues so urgent risk breach announcements are delivered naturally without interrupting active speech synthesis.
- Flash animations on tick updates respect `prefers-reduced-motion: reduce`.
